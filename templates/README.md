# Templates

This directory contains generic agent workflow templates. Copy and adapt them
into a concrete project when a workflow becomes repeated enough to deserve a
durable form.

## Contents

- `AGENTS.md`: Codex guidance for this template package.
- `decision-table.md`: choose the right surface for each kind of instruction.
- `command/`: repeated workflow entry points.
- `agent/`: specialist roles with clear responsibilities.
- `skill/`: reusable methods, templates, and checklists.
- `memory-rules/`: durable guidance and path-scoped rules.

## Usage

1. Start with `decision-table.md`.
2. Pick the smallest surface that fits the need.
3. Copy the relevant template.
4. Adapt it inside the target project.
5. Improve the template only when the lesson is reusable.
