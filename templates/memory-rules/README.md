# Memory And Rules Templates

Memory and rules control what durable guidance is available to an agent.

Use durable guidance for:

- Repository purpose
- General working principles
- Verification expectations
- Safety boundaries
- Output preferences

Use path-scoped rules for:

- Directory-specific behavior
- File-type conventions
- Local routing decisions

Design principle:

```text
Keep durable guidance short. Move specific methods to skills and path-specific
instructions to rules.
```
