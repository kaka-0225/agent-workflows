# Skill Checklist

Before creating or updating a skill, check:

- [ ] The content is a reusable method, template, or checklist.
- [ ] It is not a whole workflow.
- [ ] It is not a specialist role.
- [ ] It is not a long-term global rule.
- [ ] The description makes invocation conditions clear.
- [ ] Inputs and expected output are explicit.
- [ ] Rules include what not to do.
- [ ] Tool permissions are minimal.
- [ ] Long references are split into separate files when needed.

Avoid:

- Turning every prompt into a skill.
- Putting project-specific facts in a generic skill.
- Creating a huge all-purpose skill.
- Repeating content that belongs in durable guidance or an agent.
