# Placement Guide

Use this guide when copying or adapting `book-read`.

## Recommended Placement

For a reading workspace:

```text
workspace/
  book-read/
  books/
  notes/
    book-reading/
```

For a project or personal knowledge repository:

```text
knowledge-base/
  AGENTS.md
  book-read/
  books/
  notes/
```

## Where Notes Should Go

Generated notes should usually go outside raw book files unless the user
confirms otherwise.

Recommended:

```text
notes/book-reading/
  book-map.md
  chapter-notes.md
  reflections.md
  reading-summary.md
```

## What Not to Store Here

Do not store:

- Full copied copyrighted books
- Private journal entries unless the user explicitly wants that placement
- Sensitive personal data without confirmation
- Temporary OCR logs
- Unreviewed AI outputs mixed with final notes

## Directory Creation Rule

Before creating workflow-specific output folders, propose the exact path and
wait for user confirmation.
