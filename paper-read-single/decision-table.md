# paper-read-single Decision Table

Use this table when adding or updating workflow pieces.

| Need | Put It In |
|---|---|
| General rule for this workflow | `AGENTS.md` |
| Rule about paper files or output locations | `memory-rules/paper-rules.md` |
| Stable workflow entry point | `command/` |
| Specialist reading role | `agent/` |
| Reusable output format or checklist | `skill/` |
| Concrete notes for one paper | Outside this workflow package |
| Multi-paper comparison | A separate workflow, not here |

## Scope Rule

If a request needs more than one paper, stop and suggest a separate comparison
or batch workflow.
