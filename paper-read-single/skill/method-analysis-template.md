# Method Analysis Template

## Task

Analyze the method or design of one paper.

## Expected Output

```md
# Method Analysis

## Method Goal

## Core Components

| Component | Role | Evidence |
|---|---|---|

## Input / Output

## Training Objective Or Optimization

## Inference Or Usage Flow

## Design Rationale

## Key Formulas Or Algorithms

## Reproducibility Notes

## Uncertain Method Details
```

## Rules

- Do not fill in missing formulas or architecture details from memory.
- Separate paper evidence from inferred interpretation.
